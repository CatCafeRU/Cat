# QA документация

Документация по обеспечению качества сайта


## Тест-кейсы: два формата

### 1. `test_case.md` — Краткий чек-лист для GitHub
**Что содержит:**
- ID тест-кейса
- Шаги
- Ожмдаемый результат
Пример:
| -| -|
|---------|----------|
| id| ТС-41|
| Шаг|Войти под учетной записью «Редактор». Попытаться перейти по прямой ссылке /admin/gallery или /admin/team.|
| Результат|Доступ запрещен. Редирект на главную админки или страницу 403 Forbidden. Элементы управления пользователями скрыты в интерфейсе.|



### 2. `test_plan.xlsx` — Подробные тест-кейсы
**Что содержит:**
- ID тест-кейса
- Шаги
- Ожмдаемый результат
- С каким US связано
- Приоритет
- Статус
